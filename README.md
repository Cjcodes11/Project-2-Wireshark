# Python Wireshark Protocol and IP address Analyzer

## Project Overview
This mini program analyzes current IP addresses for warning signs and ports to determine whether they are open or closed. 

## Development Process

### Part 1: Storing port numbers and IP addresses in Lists
I created lists for this Python project to store valuable information. These lists store important information like well-known secure ports and private IPv4 addresses. 

### Part 2: Creating If, elif, and conditional statements.
During this portion, I prompt the user to type 'p' for port or 'i' for IP to scan current IP addresses and port numbers.
A for loop iterates through the current lists to determine what is secure or less secure. 

### Part 3: The final portion and future updates
By grabbing the user's input and prompting them to scan their LAN, it let's the user know what needs to be configured. 
Future updates to this program will include imported libraries and more data lists to display packet information.
